 # Assignment 25: Styled Multi-Page Project

## Project Overview
This project demonstrates the use of HTML and CSS to create attractive and well-organized web pages.

## Design Choices

### 1. Colour Palette
- Primary Colour: Dark Blue (#17365d)
- Secondary Colour: Light Brown (#d4a373)
- Background Colour: Light Grey (#eef2f7)
- Text Colour: Dark Grey (#333333)

### 2. Font Pairing
- Arial: Used for body text because it is simple and readable.
- Georgia: Used for headings to give the page a professional appearance.

### 3. CSS Styling
- CSS variables are used to maintain consistent colours and font sizes.
- Padding and margins provide proper spacing.
- Rounded corners make the layout attractive.
- Hover effects improve button interaction.
- Responsive viewport settings support different screen sizes.

## Conclusion
This project helped me understand how HTML and CSS can be combined to create consistent, attractive, and user-friendly web pages.
