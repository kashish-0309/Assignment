# Question -3
## Aim 
To learn basic terminal commands for navigating folders and files.
## Commands and their uses
1. `pwd` - Displays the current working directory.
2. `dir` - Lists files and folders in the current directory.
3. `cd foldername` - Moves into a folder.
4. `cd ..`- Moves to the parent folder.
5. `mkdir Practice` - Creates a new folder named Practice.
6. `cd Practice`- Opens the practice folder.
7. `cls`- Clears the terminal screen.
