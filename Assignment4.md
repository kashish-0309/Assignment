 # Assignment 4: Git and GitHub

## Objective
To understand Git version control and GitHub repository management.

## Learning Outcomes
- Learned to use Git commands.
- Connected a local project to GitHub.
- Practiced version control.

## Git Commands Practiced

1. `git status` - Checks the current status.
2. `git remote -v` - Shows connected remote repositories.
3. `git add` - Stages changes for a commit.
4. `git commit` - Saves changes in version history.
5. `git push` - Uploads commits to GitHub.
